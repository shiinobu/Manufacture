# Security Policy

## Supported Version

This repository is maintained as a portfolio project. Security issues affecting the current `master` branch are the primary scope for review.

## Reporting a Vulnerability

Please do not disclose sensitive credentials, exploit details, or other private information in a public issue.

If you discover a security issue, contact the repository owner privately through GitHub before publishing details.

## Secret Handling

Environment-specific credentials must be provided through environment variables or a local `.env` file. Real secrets must never be committed to the repository.
